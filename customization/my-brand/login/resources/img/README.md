# Logos and images

Files placed here override the ones shipped in the JAR, as long as they keep the same name:

| File             | Used for                                                     |
| ---------------- | ------------------------------------------------------------ |
| `logo-light.svg` | Logo in light mode (displayed 40px high)                     |
| `logo-dark.svg`  | Logo in dark mode                                            |
| `favicon.svg`    | Browser tab icon                                             |
| `login-bg.jpg`   | `unfold-full` hero image (portrait, about 1280px wide works) |

To use other file names, set `unfoldLogoUrl`, `unfoldLogoUrlDark` or `bgImage` in
`../../theme.properties`. You can delete this README.
