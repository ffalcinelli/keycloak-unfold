# Django Unfold Theme Version Alignment

This theme mirrors the design system and styling patterns of [Django Unfold Theme](https://github.com/unfoldadmin/django-unfold).

## Alignment Reference

- **Keycloak Unfold Theme Version**: `0.0.1` (SemVer `0.0.x`)
- **Supported Keycloak Target**: `26.x` (Tested on `26.7.0`)
- **Django Unfold Target Version**: `v0.101.0` (Released July 17, 2026)
- **Tailwind Version**: Tailwind CSS v4

## Key Design System Settings

- **Primary Color Accent**: Violet (`violet-600` / `#7c3aed` for light mode, `violet-500` / `#8b5cf6` for dark mode)
- **Base/Neutral Color Palette**: Slate (`slate-50` to `slate-950`)
- **Typography**: Inter (sans-serif)
- **Border Radius**: 0.375rem (default buttons/form controls), 0.5rem (cards/main panels)

## Implemented Overrides

- Custom slim scrollbars matching Django Unfold's slate scrollbars
- Focus rings matching Unfold's primary-accent outline styles
- Split login screen layouts mimicking Django Unfold aesthetics
